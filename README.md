# Research Atlas Excel Library

Professional static research library generated from nine Excel workbooks.

- **Live site:** https://research-atlas-excel-library.vercel.app
- **Datasets:** 9
- **Browsable records:** 243,110
- **Interface:** static HTML, CSS and JavaScript
- **Features:** dataset pages, sheet navigation, pagination, search and original Excel downloads

The full production data bundle is deployed on Vercel. Source pages and frontend assets are included in this repository.
